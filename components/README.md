# Components

Shared UI components live in `components/ui/`.

- `button.tsx` — button variants and sizes
- `card.tsx` — card, card title, and description
- `input.tsx` — labeled input and textarea with hint/error states
- `progress-bar.tsx` — accessible progress display
- `flashcard.tsx` — reusable study-card presentation
- `navigation.tsx` — simple responsive top navigation
- `mascot.tsx` — reusable responsive Abii image component with six named states and a missing-image fallback
- `mascot-display.tsx` — Abii image with a short title/message for common UI states
- `feedback.tsx` — empty, loading, and error states

Add the original Abii artwork to `public/mascot/`. Expected filenames and state mapping are documented in `public/mascot/README.md`. Do not redesign or replace the supplied character.
